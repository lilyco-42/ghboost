為什麼它不需要設定

其他工具要你先搞懂的東西，我們在安裝時就處理掉了。

怎麼開始

從下載到能用，大概一分鐘。

  1. 下載、解開、點兩下 install.bat 不用選路徑、不用勾選項。裝完會在桌面留一個 ghboost 捷徑。
  2. 打開面板 它會自動跑一次三個站點偵測，綠燈就是通、黃燈是慢、紅燈是不通。你什麼都不用按。
  3. 貼上訂閱網址，或選「用現成代理」 還沒有節點的話，這裡買一組，兌換後會直接給你訂閱網址。已經在用 Clash Verge 的話，填它的埠號就能直接接手，不用搬家。
  4. 按下「一鍵加速」 第一次會問一次管理員權限（改 hosts 需要）。選「是」，之後就是真的按一下。

常見問題

先用得到的三件事，寫在前面。

它會蒐集我的瀏覽紀錄或帳號密碼嗎？

不會。ghboost 全程在你自己的電腦上跑，沒有任何後端伺服器、沒有帳號系統、沒有遙測。 原始碼公開在 GitHub，你可以自己確認，也可以自己編。

為什麼第一次按會跳出「是否允許」？

加速的原理之一是改 hosts 與系統代理，這兩件事在 Windows 上需要管理員權限。 這是 Windows 的规定，不是我們多要的。只問一次；不給權限的話，偵測與「用現成代理」仍然可用。

Windows 跳出「未知的發行者」藍色警告？

這是 SmartScreen 對新發行者的標準反應——程式沒簽名時，需要靠下載量慢慢累積信譽。 專案已申請開源程式碼簽章（SignPath Foundation），通過後警告會明顯減輕。 在那之前請用 Release 頁面附的 SHA256SUMS.txt 校對檔案指紋。

怎麼完整移除？

點兩下 uninstall.bat。它會先通知程式正常退出，再還原 hosts 與系統代理、 移除開機啟動與桌面捷徑。加 -RemoveData 會連設定檔一起清掉。

為什麼不賣軟體，而是賣節點？

因為我們的目標用戶是「不想學設定」的人，而 Pro 版能賣的恰恰是 「更進階的設定」—— 賣給不想學的人更多功能，賣不出去。 況且自動挑最快節點是核心本身就有的能力，開機啟動也已經內建， 拿這些收費並不誠實。
所以客戶端維持免費開源，只做獲客；如果將來要收費，收的是 「幫你搞定節點」這件事。在那之前不會對軟體功能設付費牆。

它跟 Clash Verge 有什麼不同？

定位不同。Clash Verge 是給知道自己在做什麼的人的完整控制台； ghboost 只做一件事：讓不想設定的人，按一下就能開 Google、YouTube、GitHub。 如果你已經在用 Clash Verge，ghboost 可以直接接手它的埠號，兩者不衝突。
